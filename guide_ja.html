破滅の棘 x 無限の剣製

聖杯の残骸 -- 協力ローグライク | 攻略ガイド

ゲーム紹介

クー・フーリン（ランサー）とエミヤ（アーチャー）の二騎が汚染された地下空間を探索し、最下層B10Fの汚染核を撃破する協力ローグライク・テキストアドベンチャーです。

選択によって絆（Bond）とシナジー（Synergy）が変化し、これらの数値がエンディングを決定します。

基本操作

  • 言語切替 -- 左上の国旗ボタンで日本語/韓国語切替
  • サウンド -- 右上のスピーカーボタンでSE ON/OFF
  • セーブ -- 探索中に右上の保存ボタン（戦闘中はセーブ不可）
  • コンティニュー -- タイトル画面のCONTINUEボタン（セーブデータがある場合のみ表示）

ゲームの流れ

1. タイトル -- 難易度選択（EASY / NORMAL / HARD）後、NEW GAME

2. ターミナル -- 入力欄に trace on と入力 → 探索開始ボタンが出現

3. 探索 -- 東西南北の方向を選んで部屋を探索。5部屋以上探索で次の階への下降が可能

4. 戦闘 -- ランサーターン → アーチャーターン → 敵ターンの順番制バトル

5. B10F ボス戦 -- 最下層到達時、絆に応じてボスが決定し最終戦へ

6. エンディング -- ボス戦結果 + 絆/シナジーの数値でエンディング分岐

探索時の部屋タイプ

  • 空の通路 -- 何も起きない
  • 敵遭遇！ -- 戦闘突入
  • 補給品発見 -- アイテム取得（ルーン石、霊基の欠片、回復薬など）
  • 罠！ -- ランサーまたはアーチャーにダメージ
  • イベント -- 絆/リソースボーナス付きのストーリーイベント
  • 安全区域 -- HPとリソース（ルーン/投影力）回復

戦闘システム

クー・フーリン（ランサー）スキル

  • 突き -- 基本攻撃。リソース消費なし
  • ルーン（15） -- ルーン15消費。約1.8倍ダメージ
  • ボルク（35） -- ルーン35消費。約3.5倍ダメージ。ゲイ・ボルク

エミヤ（アーチャー）スキル

  • 干将莫耶 -- 基本攻撃。リソース消費なし
  • 投影（15） -- 投影力15消費。約2倍ダメージ
  • UBW（30） -- 投影力30消費。約3倍ダメージ。無限の剣製
  • アイアス -- 防御。次の敵攻撃ダメージ60%軽減

合同攻撃（Combo）

アーチャーターン終了後に確率で発動。発動条件：

  • シナジー15以上
  • 絆8以上
  • 確率 = 絆 x 1.5%（最大50%）

絆が高いほど合同攻撃が発動しやすくなります。

救出システム

絆10以上の時、片方のHPが0になると相方が救出しHP20まで回復させます。

一度きりではなく、絆が十分ならば繰り返し発動します。

難易度別の違い

  • EASY -- 敵HP x0.7 / 敵攻撃 x0.7 / 絆獲得 x1.3
  • NORMAL -- 基本値
  • HARD -- 敵HP x1.4 / 敵攻撃 x1.25 / 絆獲得 x0.8

HARDでは絆の蓄積が遅く、隠しエンディング達成が困難です。

エンディング一覧（全7種）

敗北エンド -- データ消失

条件：HPが0になったサーヴァント発生（救出不可時）

孤独エンド -- 各自の道

条件：絆 < 7

黙認エンド -- 戦士の礼

条件：絆 7〜14

共闘エンド -- 蒼い槍と紅い外套

条件：絆15以上（ボス未撃破）

真エンド -- 記録されない戦争

条件：ボス撃破（絆 < 20）

極限共闘エンド -- 同時NP解放

条件：ボス撃破 + 絆20以上

真・絆エンド -- 永遠に繋がる魂（隠し）

条件：ボス撃破 + 絆25以上 + シナジー40以上

※ 条件部分をタッチ/ホバーすると表示されます

エンディング回収のコツ

  • 絆を上げるには -- 各階到着時の会話イベントで好感度の高い選択肢（通常は1番目）を選んでください。絆+3〜5の選択肢があります。
  • シナジーを上げるには -- 補給品の中の「シナジー結晶」を優先的に取得してください。
  • イベント部屋でも絆が上がります。特に絆5以上で確率出現するエミヤの料理イベントは絆+3 & HP回復。
  • 隠しエンディングは絆25 + シナジー40が必要なのでEASY難易度推奨。全会話で最大好感度選択 + シナジー結晶収集が必須です。
  • ボスの強さは絆に応じて変化します：絆 < 8で弱いボス、8〜19で中間、20以上で最強ボス。隠しエンディングを狙う場合は十分な戦闘準備が必要です。

ボス情報

  • 絆 < 8 -- 魔神柱フォルネウス（HP 180 / ATK 22）
  • 絆 8〜19 -- 影のヘラクレス（HP 250 / ATK 26）
  • 絆 20+ -- 聖杯の汚染体アンリマユ（HP 320 / ATK 30）

難易度倍率が追加適用されます。HARD + 絆20以上のボスはHP 448。

周回ボーナス（Meta Bonus）

特定エンディングクリア時、次回プレイへのボーナスが表示されます：

  • 真・絆エンド -- シナジー+10、絆+5
  • 極限共闘エンド -- シナジー+5
  • 真エンド -- 絆+3

クリア時にセーブデータは削除されます（敗北エンドはセーブ維持）。
